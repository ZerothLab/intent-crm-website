# Intent walkthrough videos

Two walkthroughs are available in English and Simplified Chinese:

- Product overview: approximately 1 minute 18 seconds.
- First customer workflow tutorial: approximately 2 minutes 55 seconds.

Each language version includes its own interface recording, narration, and timed WebVTT captions. The website switches both the video and captions when the visitor changes language. The tutorial starts in an already configured workspace; see the [deployment guide](https://github.com/ZerothLab/intent-crm/blob/main/docs/deployment.md) for installation.

The footage shows the actual Intent application with fictional customer data, the deterministic Fixture model, and simulated delivery. It demonstrates the product workflow; it does not demonstrate live model quality or real customer email delivery.

Narration was generated locally with [Kokoro-82M-v1.1-zh](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh) (Apache-2.0) using [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx) (MIT). The recordings and original narration scripts are published under this repository's Apache-2.0 license. Model weights and synthesis tools are not part of the website.
